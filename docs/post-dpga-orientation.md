# Post-DPGA Orientation – AIC-SSI

**Date context:** November 2026

## Purpose of this note

AIC has submitted materials related to the Digital Public Goods Alliance review process.  

This note records how AIC-SSI should be understood in that context.

## Position

- AIC-SSI is an exploratory design repository.
- It does not constitute a claim that AIC offers a ready self-sovereign identity system.
- It does not function as a certified or production digital public good in the identity domain.
- Its value, if any, lies in careful examination of risks and constraints around identity, agency, and capture.

## Guidance for readers and contributors

- Read all claims in this repository through the lens of under-claim.
- Prefer questions and limitations over feature lists.
- Treat any code or examples as illustrative and non-authoritative.
- When in doubt, return to the core AIC principles: Ethical-from-kernel, Third Path, Non-Capture, Human Meaning, and under-claim.

This orientation remains in force until explicitly revised.
